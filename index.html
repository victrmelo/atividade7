Respostas

1) Docker registry é onde ficam armazenadas imagens Docker, como o Docker Hub. Versionamento é o uso de tags.

2) O comando docker login serve para autenticar no Docker Hub.

3) O docker push envia a imagem local para o Docker Hub.

4) Versionar corretamente é usar tags organizadas como v1, v2, v04112025 etc.

5) Tag estável é usada para versões finais. Tag volátil muda com frequência.
